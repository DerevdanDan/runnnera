# Runnnera

I want to build a web app that connects to Strava data and counts how many km the users have run during the month. In the end of each month the user with least km will have to spin the wheel. Each user in the beginning of every month creates 3 custom punishments that are put in the wheel. The users at the moment are Alvaro, Daniil, Mario. When logging into the web app, it asks for the necessary access to fetch the Strava activity data.
